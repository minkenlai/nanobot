fix(memory): ensure consolidate_messages returns summary string instead of boolean

Fixed a bug where `MemoryConsolidator.consolidate_messages` returned a boolean
(`is not None`) instead of the actual summary string. This caused the `/compact`
command to inject a boolean into the session history, leading to LLM failures
in subsequent turns.

- Updated `consolidate_messages` to return the result of `store.consolidate` directly.
- Added `tests/memory/test_consolidator.py` to verify return types.
- Updated `CLAUDE.md` to include `/compact` in the command documentation.
