# Target User Profile

## Counterparty Overview
- **Who they are:** Prospective students, parents, visiting dancers, current members, and general community inquiries reaching out via public channels (WhatsApp, Telegram, website chat widget).
- **Experience Levels:** Ranges from complete beginners looking for introductory offers and trial classes to experienced dancers inquiring about specific styles, advanced workshops, or social events.
- **Communication Context:** Mobile and web chat. Expect quick, direct questions about class schedules, pricing, parking, dress codes, instructor availability, and studio location.
- **Tone Expectation:** Welcoming, helpful, concise, and easy to read on mobile screens.
